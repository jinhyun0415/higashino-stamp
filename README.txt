히가시노 게이고 도장깨기 PWA — 첫 버전 디자인 복원판

포함 파일
- index.html: 첫 버전의 UI와 98권 목록을 기반으로 복원
- manifest.json: 휴대폰 앱 설치 설정
- service-worker.js: 오프라인 캐시 및 업데이트
- icon.svg: 앱 아이콘

GitHub Pages에 업데이트하는 방법
1. GitHub 저장소에서 Add file > Upload files를 선택합니다.
2. 이 폴더 안의 파일 4개를 저장소 루트에 업로드합니다.
3. 같은 이름의 파일을 덮어쓰고 Commit changes를 누릅니다.
4. 1~3분 기다린 후 사이트 주소를 다시 엽니다.

기록 보존
- 기존 PWA의 higashino_stamp_v1 기록을 새 기록 형식으로 자동 복사하도록 구성했습니다.
- 업데이트 직후 기록이 바로 보이지 않으면 앱을 완전히 닫고 다시 열어 주세요.
- 기록을 지우거나 사이트 데이터/브라우저 데이터를 삭제하지 마세요.

참고
- 작품 목록은 처음 버전에 있던 목록을 복원한 것으로, 공식 완전 서지 목록임을 보장하지 않습니다.
- 독서 기록은 브라우저/기기 안에 저장되며 기기 간 자동 동기화는 되지 않습니다.
