히가시노 게이고 도장깨기 PWA 시작 파일

포함 파일: index.html, manifest.json, service-worker.js, icon.svg

사용 순서:
1. ZIP 압축을 풉니다.
2. 네 파일을 GitHub 저장소 최상위에 올립니다.
3. 저장소 Settings > Pages에서 배포를 켭니다.
4. GitHub Pages가 제공한 HTTPS 주소를 안드로이드 Chrome에서 엽니다.
5. Chrome 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

독서 기록은 기기의 브라우저 저장소에 저장되며 다른 기기와 자동 동기화되지 않습니다.
책 목록은 시작용 목록이며 완전한 전작 목록이 아닙니다. 목록에 없는 책은 앱의 '책 추가'로 추가할 수 있습니다.
